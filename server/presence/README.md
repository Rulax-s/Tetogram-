# Сервер «Друзья в Тетограме»

Маленький сервер, который знает только одно: какие Telegram ID прислали сигнал «я в Тетограме» за последние 5 минут (и не выключили «Показывать другим»). Ничего не пишется на диск: сигналы живут в памяти и сами истекают. Сообщения, контакты и чаты сюда не попадают. Подтверждения аккаунта нет — метку теоретически можно подделать, это осознанное упрощение.

Хватает бесплатного тарифа Cloudflare Workers.

Рабочий экземпляр: `https://tetogram-presence.rulaxgames.workers.dev` (вшит в приложение по умолчанию).

## Запуск (один раз, ~5 минут)

1. Зарегистрируйтесь на dash.cloudflare.com (бесплатно).
2. На компьютере с Node.js:
   ```
   cd server/presence
   npx wrangler login
   npx wrangler deploy
   ```
3. Wrangler покажет адрес вида `https://tetogram-presence.<имя>.workers.dev`. Откройте его в браузере — должно быть `"ok":true`.
4. В Тетограме: Тетолабс → «Друзья в Тетограме» → «Сервер присутствия» → вставьте адрес.

Пришлите разработчику адрес — его можно вшить по умолчанию, чтобы друзьям ничего не вводить.

## API

Все запросы — `POST` с заголовком `X-Tetogram: 1`.
`/beat {uid, visible}`; `/status {ids[≤100]}` → `{online}`.

Без компьютера: создать API-токен по шаблону «Edit Cloudflare Workers» и выполнить `wrangler deploy` с `CLOUDFLARE_API_TOKEN` и `CLOUDFLARE_ACCOUNT_ID` в любой среде с Node.js.
