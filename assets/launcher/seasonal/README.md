# Подготовленные сезонные изображения

Скопируйте исходные **квадратные PNG или JPEG** в эту папку. Не используйте произвольные заглушки. Имена:

| Tetogram / Касане Тето | Mikugram / Хацунэ Мику |
|---|---|
| tetogram_spring.png | mikugram_spring.png |
| **tetogram_summer.jpg — подключена** | mikugram_summer.png |
| tetogram_autumn.png | mikugram_autumn.png |
| tetogram_winter.png | mikugram_winter.png |

Семь уже имеющихся иллюстраций находятся в Android drawable-nodpi; catalog.json связывает их с этими именами без дублирования исходных PNG. Повторно сохранённый владельцем JPEG подключён как летняя Тето по его указанию. Это оригинальный файл 1536×1536, без перерисовки, кадрирования или перекодирования. Все восемь вариантов доступны.

PNG/JPEG с basename tetogram_summer поддерживаются одинаково; нельзя одновременно хранить два формата одного ресурса. Можно загрузить файл в эту папку через веб-интерфейс GitHub и сделать обычный commit в master: существующий Actions запускает подготовку и APK-сборку. Никакие Secrets менять не нужно.

Локально после копирования:

```sh
python3 scripts/prepare-seasonal-icons.py
python3 scripts/check-launcher-icons.py
```

Генератор не перерисовывает, не обрезает и не перекодирует изображения. Он проверяет квадратный PNG/JPEG 256–8192 px и подготавливает Android resources, catalog и блок новых activity-alias. Другие части Manifest и legacy aliases сохраняются. --check проверяет воспроизводимость без записи. CI выполняет генерацию в обоих checkout (source checks и build).

Для отсутствующего изображения нет фиктивного drawable: соответствующий alias подготовлен как выключенный **не launcher-компонент**, без icon/intent-filter. В UI видны название сезона, сообщение об отсутствующем файле и путь; Apply недоступна. При добавлении файла генератор автоматически добавит настоящие resources/launcher intent-filter и вариант станет доступен. В текущем дереве все восемь изображений подключены; отсутствие любого будущего входного файла не маскируется заглушкой.

Новые adaptive foreground целиком вписаны в центральный safe circle 66dp: квадрат 46.44dp внутри 108dp слоя (inset28.5%). Визуальный viewport72dp даёт scale0.645; диагональ квадрата65.68dp. Есть один background, без stroke/дополнительной непрозрачной рамки и без второй растровой маски. Чёрные углы уже присутствуют в предоставленных композициях; они не закрашиваются и не дорисовываются. Для full-bleed без полей нужны отдельные исходные foreground/background слои. Реальное поведение Samsung One UI необходимо проверить на устройстве.
