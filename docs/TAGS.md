# Теги чатов (v42)

- Свои цветные метки (до 30, 7 цветов темы) — чат → ⋮ → Теги или Тетолабс → Теги. Видны плашками в списке чатов той же отрисовкой, что и теги папок Telegram; теги папок Premium по-прежнему доступны только с Premium.
- «Чаты с этим тегом» — быстрый список с переходом в чат.
- Хранение: `SharedPreferences tetogram_tags_u<uid>` (Properties, schema 1, неизвестная схема не перезаписывается), модель `ChatTags` покрыта тестами.
