# Перевод чатов (v41)

Собственный перевод Tetogram. Платный перевод Telegram Premium не используется и не разблокируется.

## Как работает
- **Входящие.** В чате, где перевод включён (⋮ → Перевод или подсказка «Чат на языке: …»), текст и подписи входящих сообщений рядом с экраном переводятся на язык приложения (или выбранный в настройках). Оригинал: долгое нажатие → «Оригинал».
- **Исходящие.** Если включено «Переводить мои сообщения» и язык чата известен (определён по ≥3 входящим или выбран вручную), перед отправкой показывается перевод: «Отправить перевод», «Без перевода», «Отмена». Собеседник получает перевод, а на этом телефоне в пузыре виден исходный текст. Что ушло на самом деле: долгое нажатие → «Отправленный текст».
- **Подсказка.** Определение языка по входящим (ML Kit language-id, на устройстве); подсказка показывается один раз за запуск для чата.

## Движки
- **На устройстве** (по умолчанию) — ML Kit Translate, модель ~30 МБ на язык, скачивается при первом использовании. Текст не покидает телефон.
- **Google Cloud Translation v2 / DeepL** — с личным API-ключом пользователя (ключ хранится только в `tetogram_translate` prefs). Неофициальные эндпоинты не используются.

## Данные
- `SharedPreferences tetogram_translate`: engine, key.*, target, outgoing, `u<uid>.chats`, `u<uid>.lang.<dialog>`, `u<uid>.sent` (до 1000 пар «отправленный перевод → исходный текст»).
- Переводы входящих — только в памяти (LRU 2000), неудачи повторяются не чаще раза в минуту.
- Существующие форматы данных не менялись; миграция не нужна.

## Ограничения
- Форматирование (жирный, ссылки-тексты) в переводе не сохраняется. Сообщения длиннее 4000 символов не переводятся.
- Если сервер изменит текст при отправке, локально будет показан перевод вместо исходника.
