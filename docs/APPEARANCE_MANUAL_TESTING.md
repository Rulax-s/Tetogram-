# Оформление 0.4.0 — Android-проверки

Статус всех сценариев ниже: **NOT RUN агентом**. JVM/SQLite/source/APK checks не заменяют эту матрицу. Не удалять приложение для установки обновления; использовать ту же подпись и более высокий versionCode. Не использовать реальные аккаунты без отдельного согласия владельца.

## Базовые сценарии

- Обновить 0.3.1 поверх существующей установки; проверить аккаунты, локальную историю, Reply, UUID/иконки/папки/правила и unread-раздел. Старые настройки оформления не должны сбрасываться.
- Проверить вход Настройки → Оформление Tetogram, вложенные редакторы, Back и системные Insets: Android 14+, светлая/тёмная темы, жесты/три кнопки, портрет/альбом, маленький экран.
- Применить каждый встроенный пресет; поменять native Telegram-тему и автоночной режим. Сравнить заголовки, нижние вкладки, список и открытый чат. Проверить наследование/Reset и отсутствие глобального изменения при редактировании одного чата.
- Два аккаунта: разное оформление; переключить во время открытого picker/конвертации/экспорта. Старый callback не должен изменять другой UID.
- Раздел без папок, смешанный раздел, одна папка в двух разделах: открыть один чат из каждого контекста и через поиск/уведомление. Проверить устойчивый приоритет явного chat/topic override.

## Редактор и пресеты

- Простой режим: основной цвет, режим, стиль/прозрачность сообщений, фото/видео; проверить live preview. Расширенный: поиск RU/EN, HEX/RGB/HSV/HSL, alpha, градиенты, избранные/последние, pipette у края и центра изображения.
- Отмена picker/пипетки/редактора не сохраняет предварительные цвета. Undo возвращает прежнее значение. Save as preset/rename/duplicate/edit не применяют пресет к текущему экрану; Apply применяет.
- Проверить предупреждение низкой контрастности и восстановление. Текст поверх произвольного видео/изображения проверяется глазами отдельно.
- Incoming/outgoing: текст/эмодзи/entities, время, проверки доставки, длинный текст, Reply/цитата/спойлер, фото/видео/альбом/подпись, голосовые/круглые/опросы/реакции, удалённые локальные сообщения. Проверить большие/разные углы, хвост, контур, тень, прокрутку/recycle без подмены содержимого.

## Медиа и жизненный цикл

- Photo Picker без полного разрешения галереи: JPEG/PNG с alpha/WebP, EXIF 90/270, большая вертикальная/горизонтальная фотография. Native crop: перемещение/zoom/отмена; старый фон сохраняется при отмене/ошибке.
- Видео: native trim/crop/filter, отсутствие звука, fill/fit/zoom/pan, скорость/loop, первый/текущий кадр обложки. После изменения FPS/качества подтвердить Edit current video: параметры подготовки применяются при кодировании.
- Сравнить геометрию видео и cover: первый кадр, поворот, клавиатура, SimpleGlass, ошибка/неподдерживаемый codec. До Android 12 blur-видео должно стать static cover, как объяснено редактором.
- Home/Back, выключение экрана, другой чат/профиль, PhotoViewer/StoryViewer, Lite Mode, battery saver, выключенные анимации: невидимый видеослой не декодируется; возврат не создаёт несколько плееров и не оставляет чёрный слой.
- Локальный баннер собственного профиля: preview, crop, цвета имени/статуса, высота/радиус, opt-in parallax, сворачивание шапки, открытие avatar/gallery, клики Back/Edit. Публичная аватарка и другие клиенты не меняются.

## Хранение, перенос и ярлык

- Перезапуск/process death/поворот, отзыв временного URI grant: сохранённые private media доступны. Отсутствующий/испорченный файл показывает fallback без crash.
- Один файл используется scope и неактивным preset: заменить фон только у одного — второй не теряет медиа. Cancel и успешное Save очищают только неиспользуемые appearance assets.
- Export без медиа/с фото/с видео; import в draft; Cancel не применяет. Сравнить palette/формы/общие ссылки после импорта. Некорректный/слишком большой ZIP отклоняется.
- Native alias переключается штатным selector; произвольный label/image/emoji создаёт только явно подтверждённый pinned shortcut. Проверить native crop, отмену, отключение shortcut и ручное удаление лаунчером. APK package/certificate/system label сохраняются.

## Границы проверки

Сравнить обычные чаты, уведомления, Mini Apps, Premium, секретные чаты, форум, архив, поиск, серверные папки и рекламу до/после. Тестировать на Android с доступными кодеками; успешная компиляция не подтверждает gestures/EXIF/loop/consumption. Никакие приватные сообщения, сессии, токены или номера телефонов в отчёт не включать.
