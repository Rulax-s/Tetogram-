# Друзья в Тетограме (v44)

- В шапке личного чата: «в сети · в Тетограме», если Telegram показывает человека в сети **и** его Тетограм открыт на экране (сигнал не старше 5 минут) **и** у него включено «Показывать другим».
- Пока приложение на переднем плане, раз в 2 минуты отправляется сигнал на сервер присутствия (`TetoPresence`); в фоне сигналы не шлются. Выключатель «Показывать другим» сразу снимает метку.
- Подтверждения аккаунта нет (сознательное упрощение): сервер принимает сигнал по Telegram ID. Запрос статуса — только для людей, которых Telegram уже показывает в сети, кэш 60 с.
- Сервер: `server/presence` (Cloudflare Worker + Durable Object), инструкция в его README. Пока адрес не задан, функция неактивна.
