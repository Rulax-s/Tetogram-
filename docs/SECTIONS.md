# Tetogram 0.3.0 — разделы и необязательные папки

Настройки → Tetogram Labs → Разделы. При первом запуске не создаются ни разделы, ни папки: доступен существующий список чатов без навязанных вкладок. После создания раздела он пуст, пока владелец не добавит чаты, правила или папки. Удаление последнего раздела оставляет пустой настраиваемый экран, а не создаёт «Все чаты».

Редактор позволяет создать/переименовать/удалить раздел, выбрать символ/эмодзи, переместить выше/ниже и выбрать default. Чаты выбираются штатным DialogsActivity picker. Добавление вручную имеет приоритет над автоматическими правилами; явные исключения имеют приоритет над обоими. Правила: контакты, не контакты, группы, каналы, боты, непрочитанные, исключение muted/archive. События read/mute/contacts обновляют локальные проекции через штатный adapter diff, без пересоздания сообщений; заведомо пустой раздел не инициирует массовую пагинацию списка чатов. Без категорий новые чаты автоматически не появляются. Секретные чаты могут быть выбраны вручную: их сообщения и шифрование не меняются.

Папки полностью необязательны. Без папок показывается непосредственный список. С папками — существующий FilterTabsView: можно привязать серверную Telegram-папку, создать или использовать локальную. Общая вкладка «Чаты раздела» появляется только при наличии папок и явном включении опции (default off). Порядок папок отдельный для каждого раздела. Ключи `tg:<server filter ID>` и `local:<UUID>` сохраняются вместо индексов. Одна папка и один чат могут присутствовать в нескольких разделах. Отвязка не вызывает Telegram API и не удаляет серверную папку. Локальная папка редактируется через меню её строки либо общий список локальных папок.

Если Telegram-папка переименована/переставлена, имя обновляется по ID, локальный порядок сохраняется. Недоступная/удалённая папка отмечается в редакторе и не создаёт фиктивную вкладку; привязка сохраняется, чтобы не потерять её при ещё не загруженном server cache. Последний выбранный ключ не заменяется индексом. Premium-lock серверной папки не обходится. Настройки серверных папок по-прежнему доступны в стандартном экране Telegram.

Внизу справа одна кнопка-стрелка. Она раскрывает вертикальный прокручиваемый список кружков снизу вверх в порядке настройки. Активный раздел выделен цветом темы, длинное нажатие показывает имя; после выбора меню сворачивается. Скрытие/возвращение кнопки использует штатный scroll-механизм Telegram; при скрытии меню закрывается. Длинное нажатие на стрелку открывает управление разделами. В существующем меню ⋮ доступны новый чат, камера, разделы и архив. Доступ к контактам и журналу звонков перенесён в Настройки. Нижняя панель: Чаты / Настройки / Профиль. Предложения добавить/скрыть четвёртую вкладку звонков убраны из журнала, чтобы не показывать неработающие настройки; создание и история звонков сохранены.

## Хранение и интеграция

`SectionConfig` — чистая Java-модель и versioned Properties codec, без Android/network dependencies. `SectionsStore` — private SharedPreferences `tetogram_sections_v1_u<Telegram user ID>`; запись проверяет owner UID, а не слот аккаунта. UUID разделов и локальных папок, чаты, исключения, flags, порядок, general toggle, default, last folder переживают перезапуск. Неизвестная/повреждённая схема не перезаписывается редактором.

`SectionDialogs` проецирует существующие TLRPC.Dialog. Сообщения и их объекты/история не копируются. Local Reply, история удаления и эфемерные сообщения не затронуты. Порядок диалогов берётся из штатного списка. Серверные папки используют реальные DialogFilter и штатные режимы 7/8; локальные страницы получают отдельные проекции по идентичности адаптера, а не по общему индексу текущей страницы. Это важно при анимированном переключении двух страниц. Закрепление и архив используют штатные действия; архивные чаты остаются внутри архива. Поиск остаётся штатным глобальным поиском Telegram, не добавляет найденные чаты в раздел автоматически.

`FilterTabsView.localOnlyTabs` запрещает автоматическое переименование вкладки во «Все чаты» и серверный reorder из локального интерфейса. Стандартный компонент в остальных экранах работает как раньше. Перестановка локальных вкладок выполняется в редакторе раздела, без запросов изменения серверной папки. Явные действия пользователя внутри настоящей серверной папки (например, закрепление) продолжают использовать штатную реализацию.

## Проверки

19 новых JVM-тестов покрывают отсутствие принудительных сущностей, пустой/без папок/одна/несколько/смешанный раздел, optional general, повторное включение чата и папки, отвязку, Properties roundtrip с Unicode/ID/order/default/last, изоляцию namespace аккаунтов, правила и исключения, недоступную серверную папку, удаление разделов/локальной папки, 150 разделов без искусственного лимита и несовместимую схему. Это проверки модели, не Android UI.

Ручная Android-проверка (NOT RUN агентом):

1. Все пять видов разделов: чаты, одна папка, несколько, mixed с general on/off, полностью пустой.
2. Одинаковые чат и папка в двух разделах, разные порядки папок; отвязка без server delete.
3. Перезапуск и default section, last folder; переключение двух аккаунтов без смешивания настроек.
4. Изменение/удаление Telegram-папки другим клиентом и обновление привязки.
5. Закрепление/перестановка pinned, скрытый архив и архивные совпадения правил, unread/mute, поиск.
6. Тап и горизонтальный свайп между двумя локальными папками: правильные имена/аватары, открывается именно показанный чат; отменённый свайп не меняет last folder.
7. Много разделов на маленьком экране: кружки прокручиваются, меню закрывается после выбора, вниз скрывается/вверх возвращается.
8. Светлая/тёмная тема, RTL, landscape; Контакты и Звонки через Настройки, compose и камера через ⋮.
9. Отправка/получение, Local Reply, удалённые и эфемерные сообщения, Premium, Mini Apps.

Редактирование сообщений/база истории не меняются. История редактирования, ранее явно недоступная в Labs, не объявляется реализованной этим заданием. Реальное устройство/ADB и учётные записи не использовались.

# Доработка 0.3.1

## Локализация

Причина `LOC_ERR:null`: `TelegramBuildAppPlugin` передавал в генератор binary language packs только `strings.xml`; строки отдельных `tetogram*.xml` попадали в Android resources/R, но отсутствовали в `localization_en.bin`/`localization_ru.bin`. Входы двух сборочных плагинов расширены только файлами Tetogram. `LocaleController` и приоритет внешних пакетов не меняются. RU получает русский, EN — английский, остальные локали наследуют EN для отсутствующих Tetogram-ключей. `scripts/check-localization.py` проверяет XML/используемые ключи до сборки и реальные EN/RU assets + `string_resource_ids.bin` внутри APK после неё.

## Меню

Новые `SectionMenuState`/`SectionMenu`: открытие снизу вверх с alpha/scale .8→1/translation, обратное закрытие; 210 мс движения + до 80 мс stagger. Стрелка поворачивается одновременно. GONE устанавливается после завершения AnimatorSet. Системный duration scale учитывается самими Android-аниматорами; отключённые анимации применяются мгновенно. Токены завершения отбрасывают устаревшие callbacks при повторных нажатиях, смене аккаунта/уходе с экрана. Во время появления/исчезновения кружки не принимают нажатия. Порог ручной прокрутки — 24 dp, направление меняет накопление; возврат основной кнопки не раскрывает меню.

Долгое нажатие использует haptic feedback и открывает существующий `SectionsActivity` по UUID после закрытия меню. Проверяется реальный owner Telegram UID; индексы кружочков не используются. Для системного раздела открываются его настройки в общем экране разделов.

## Оформление и локальные файлы

Блок «Оформление раздела»: название, тот же `SectionCircle`, что в меню, предпросмотр, любое Unicode/ZWJ-эмодзи, встроенные theme-colored иконки, выбор фото, сброс, явные сохранить/отменить. Это draft: отмена не изменяет сохранённую иконку.

Фото: системный Photo Picker (Android 13+) или SAF для одного `image/*`, без запроса полного доступа. URI копируется в приватный временный файл на фоновой очереди. Далее используется настоящий `ImageUpdater.openPhotoForEdit` → `PhotoViewer.SELECT_TYPE_AVATAR` (та же круглая маска, pinch/drag, EXIF orientation, затемнение, Done/Cancel). Добавлен account-aware overload ImageUpdater; прежний конструктор сохраняет поведение остальных экранов. `setUploadAfterSelect(false)` запрещает upload. После Done результат оптимизируется до JPEG 512×512 с bounded decode, затем показывается круглый draft; применение только по «Сохранить оформление».

Файлы: private `files/tetogram_section_icons/u<Telegram UID>/<section UUID>/<image UUID>.jpg`, временный ввод `.input`. В preferences — тип, emoji/имя стандартной иконки, имя файла, revision; Base64 нет. Preferences записываются с проверкой commit до удаления старого файла. Неактуальные parent snapshots сохраняют более новую icon revision. Неиспользуемые собственные файлы очищаются после успешной записи; pending editor защищён от cleanup, отмена удаляет его candidate. Пропавшее/повреждённое изображение имеет стандартный placeholder. Исходники галереи не изменяются.

Миграция Properties schema 1 (0.3.0) → 2 additive: UUID, порядок, direct/excluded chats, rules, folders, default и last folder сохраняются; старый `icon` становится emoji. Файл preferences с UID не переименовывается. Повреждённая/будущая схема не перезаписывается.

## Счётчики и временные «Непрочитанные»

`SectionUnread` читает только штатные cached Dialogs, `MessagesController.getDialogUnreadCount` и `isDialogMuted`. Категории и локальные правила вычисляются по snapshot; членство каждой привязанной папки вычисляется один раз, не на каждом кадре. Для серверных папок используется native `DialogFilter.includesDialog`, Premium-lock не обходится.

Счётчик обычного раздела — сумма unread messages в объединении прямых чатов/правил/локальных и Telegram-папок, с дедупликацией по полному dialog ID. Явное исключение раздела имеет приоритет над членством в папках. Финальная проверка mute обязательна, включая временный, групповой, канальный и global/category mute: даже mention в muted-чате не добавляет его в обычный badge. Один чат может считаться в разных разделах независимо.

Бейдж — native `CounterView` поверх верхнего правого края `SectionCircle`, картинка не сдвигается; цвета темы, zero скрыт, compact 99+ включён по умолчанию. В настройках есть show counters, compact, отключённый checked-пункт исключения muted. Настройки account-local и сохраняются.

Системный `system:unread` — только UI/derived state, не элемент `SectionConfig.sections`. По умолчанию enabled, mute excluded; отдельная настройка разрешает учитывать muted только здесь. Иконка 📩 стоит над пользовательскими кружками. Показывается при наличии eligible unread chats; если активен, сохраняется при опустевшем списке с native empty state «Все сообщения прочитаны». После явного выхода (другой раздел/Back) пустой кружок скрывается. Back также позволяет вернуться в обычный список, когда пользовательских разделов ещё нет. Никаких папок или фиксированных пользовательских разделов функция не создаёт.

Обновление: native reload/read/mute/contacts/folder events, короткий batch, onResume и foreground timer 15 секунд для истечения native mute. Timer не выполняет Telegram API requests и останавливается при pause/destroy. Порядок/объекты Dialog не копируются в отдельную message history. Незагруженные неизвестные данные не придумываются; используются текущие штатные cached данные. Ручной unread_mark с нулевым реальным count оставляет чат в списке, но не создаёт фиктивное сообщение для badge.
