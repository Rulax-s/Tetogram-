# Tetogram 0.3.0 — разделы и необязательные папки

Настройки → Tetogram Labs → Разделы. При первом запуске не создаются ни разделы, ни папки: доступен существующий список чатов без навязанных вкладок. После создания раздела он пуст, пока владелец не добавит чаты, правила или папки. Удаление последнего раздела оставляет пустой настраиваемый экран, а не создаёт «Все чаты».

Редактор позволяет создать/переименовать/удалить раздел, выбрать символ/эмодзи, переместить выше/ниже и выбрать default. Чаты выбираются штатным DialogsActivity picker. Добавление вручную имеет приоритет над автоматическими правилами; явные исключения имеют приоритет над обоими. Правила: контакты, не контакты, группы, каналы, боты, непрочитанные, исключение muted/archive. События read/mute/contacts обновляют локальные проекции через штатный adapter diff, без пересоздания сообщений; заведомо пустой раздел не инициирует массовую пагинацию списка чатов. Без категорий новые чаты автоматически не появляются. Секретные чаты могут быть выбраны вручную: их сообщения и шифрование не меняются.

Папки полностью необязательны. Без папок показывается непосредственный список. С папками — существующий FilterTabsView: можно привязать серверную Telegram-папку, создать или использовать локальную. Общая вкладка «Чаты раздела» появляется только при наличии папок и явном включении опции (default off). Порядок папок отдельный для каждого раздела. Ключи `tg:<server filter ID>` и `local:<UUID>` сохраняются вместо индексов. Одна папка и один чат могут присутствовать в нескольких разделах. Отвязка не вызывает Telegram API и не удаляет серверную папку. Локальная папка редактируется через меню её строки либо общий список локальных папок.

Если Telegram-папка переименована/переставлена, имя обновляется по ID, локальный порядок сохраняется. Недоступная/удалённая папка отмечается в редакторе и не создаёт фиктивную вкладку; привязка сохраняется, чтобы не потерять её при ещё не загруженном server cache. Последний выбранный ключ не заменяется индексом. Premium-lock серверной папки не обходится. Настройки серверных папок по-прежнему доступны в стандартном экране Telegram.

Внизу справа одна кнопка-стрелка. Она раскрывает вертикальный прокручиваемый список кружков снизу вверх в порядке настройки. Активный раздел выделен цветом темы, длинное нажатие показывает имя; после выбора меню сворачивается. Скрытие/возвращение кнопки использует штатный scroll-механизм Telegram; при скрытии меню закрывается. Длинное нажатие на стрелку открывает управление разделами. В существующем меню ⋮ доступны новый чат, камера, разделы и архив. Доступ к контактам и журналу звонков перенесён в Настройки. Нижняя панель: Чаты / Настройки / Профиль.

## Хранение и интеграция

`SectionConfig` — чистая Java-модель и versioned Properties codec, без Android/network dependencies. `SectionsStore` — private SharedPreferences `tetogram_sections_v1_u<Telegram user ID>`; запись проверяет owner UID, а не слот аккаунта. UUID разделов и локальных папок, чаты, исключения, flags, порядок, general toggle, default, last folder переживают перезапуск. Неизвестная/повреждённая схема не перезаписывается редактором.

`SectionDialogs` проецирует существующие TLRPC.Dialog. Сообщения и их объекты/история не копируются. Local Reply, история удаления и эфемерные сообщения не затронуты. Порядок диалогов берётся из штатного списка. Серверные папки используют реальные DialogFilter и штатные режимы 7/8; локальные страницы получают отдельные проекции по идентичности адаптера, а не по общему индексу текущей страницы. Это важно при анимированном переключении двух страниц. Закрепление и архив используют штатные действия; архивные чаты остаются внутри архива. Поиск остаётся штатным глобальным поиском Telegram, не добавляет найденные чаты в раздел автоматически.

`FilterTabsView.localOnlyTabs` запрещает автоматическое переименование вкладки во «Все чаты» и серверный reorder из локального интерфейса. Стандартный компонент в остальных экранах работает как раньше. Перестановка локальных вкладок выполняется в редакторе раздела, без запросов изменения серверной папки. Явные действия пользователя внутри настоящей серверной папки (например, закрепление) продолжают использовать штатную реализацию.

## Проверки

19 новых JVM-тестов покрывают отсутствие принудительных сущностей, пустой/без папок/одна/несколько/смешанный раздел, optional general, повторное включение чата и папки, отвязку, Properties roundtrip с Unicode/ID/order/default/last, изоляцию namespace аккаунтов, правила и исключения, недоступную серверную папку, удаление разделов/локальной папки, 150 разделов без искусственного лимита и несовместимую схему. Это проверки модели, не Android UI.

Ручная Android-проверка (NOT RUN агентом):

1. Все пять видов разделов: чаты, одна папка, несколько, mixed с general on/off, полностью пустой.
2. Одинаковые чат и папка в двух разделах, разные порядки папок; отвязка без server delete.
3. Перезапуск и default section, last folder; переключение двух аккаунтов без смешивания настроек.
4. Изменение/удаление Telegram-папки другим клиентом и обновление привязки.
5. Закрепление/перестановка pinned, скрытый архив и архивные совпадения правил, unread/mute, поиск.
6. Тап и горизонтальный свайп между двумя локальными папками: правильные имена/аватары, открывается именно показанный чат; отменённый свайп не меняет last folder.
7. Много разделов на маленьком экране: кружки прокручиваются, меню закрывается после выбора, вниз скрывается/вверх возвращается.
8. Светлая/тёмная тема, RTL, landscape; Контакты и Звонки через Настройки, compose и камера через ⋮.
9. Отправка/получение, Local Reply, удалённые и эфемерные сообщения, Premium, Mini Apps.

Редактирование сообщений/база истории не меняются. История редактирования, ранее явно недоступная в Labs, не объявляется реализованной этим заданием. Реальное устройство/ADB и учётные записи не использовались.
