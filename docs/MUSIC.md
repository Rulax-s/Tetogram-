# Музыка Тетограма (v47)

- Тетолабс → «Музыка»: свои плейлисты (название, цвет), «Недавно слушал», «Часто слушаю» (≥2 прослушиваний), «Все треки плейлистов», «Вся моя музыка» (поиск по всем чатам и каналам через messages.searchGlobal + фильтр Music).
- В чате: удерживайте трек → «В плейлист» (для альбома — все треки альбома).
- Плейлист: «Играть», «Перемешать», запуск с любого трека, поиск, перетаскивание, «Показать в чате», «Убрать».
- Хранятся только ссылки (чат + сообщение) и название/исполнитель/длительность для списка: `SharedPreferences tetogram_music_u<uid>`, модель `Playlists` (schema 1, тесты PlaylistsTest). Аудио не копируется; удалённые треки пропускаются при проигрывании.
- Проигрывание — штатный плеер Telegram. `MediaController.tetogramKeepOrder` сохраняет порядок плейлиста (обычно Telegram сортирует очередь по ID сообщений); история прослушиваний записывается при старте другого трека.
- Секретные чаты в плейлисты не попадают (их сообщения не загружаются по ID).
