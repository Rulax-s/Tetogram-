# Tetogram / Mikugram — системное оформление, code169

Одна APK org.tetogram.messenger. Название Android application остаётся Tetogram; label активного launcher alias — Tetogram или Mikugram. Не меняются package, подпись, Firebase, аккаунты, разрешения, уведомления и deep-link Activity.

## Состояние ресурсов

**Подготовлены восемь canonical aliases и логическая матрица 2×4. В текущих файлах есть только семь реальных сезонных изображений.** Отсутствует летняя Тето. Нужен assets/launcher/seasonal/tetogram_summer.png; все имена, порядок подключения и автоматическая генерация в assets/launcher/seasonal/README.md.

TetogramSummer до предоставления рисунка — выключенный не launcher-компонент без icon/intent-filter. В редакторе это явно недоступный вариант, не подмена базовой картинкой или чужим персонажем. Если Auto требует отсутствующий рисунок, текущая иконка сохраняется; UI показывает предупреждение. Нельзя объявлять восемь изображений готовыми.

## UI и области хранения

Оформление → Название и иконка приложения: сегменты Tetogram/Касане Тето и Mikugram/Хацунэ Мику; Auto/весна/лето/осень/зима; крупный предпросмотр с label; горизонтальная галерея четырёх сезонов выбранного персонажа; три маски. Выбор обновляет preview сразу и применяет системное состояние только после Apply. Reset предлагает стандартный Tetogram T и требует Apply. Прежние совместимые иконки находятся отдельно; заблокированные Premium/Turbo не показываются в галерее.

Системный экран больше не сохраняет AppearanceStore аккаунта. Персональный ярлык вынесен в AppearanceShortcutActivity с прежними UID-based launcher.label/icon.file/emoji/iconScale, Photo Picker, native avatar crop и явным подтверждением pin. Его сохранение не переустанавливает системный alias и не меняет выбранного персонажа.

LauncherIconSettings хранится в общем SharedPreferences tetogram_launcher/schema2: seasonal, brand, automatic, manualSeason, lastAlias, revision. Legacy seasonal/brand/season читаются без сброса. Ручной сезон сохраняется при переходе в Auto. Изменение персонажа не меняет automatic/manualSeason. Date-only alias bookkeeping не увеличивает revision пользовательского выбора.

## Миграция и переключение

Старые семь Miku…Icon/Teto…Icon и шесть классических aliases сохраняются в Manifest. Новые canonical names: TetogramSpring/Summer/Autumn/Winter и MikugramSpring/Summer/Autumn/Winter. Эквивалентная действующая legacy-иконка не заменяется при запуске только ради переименования компонента. Для явного перехода на новый safe-zone ресурс выберите тот же бренд/сезон и нажмите Apply. Auto естественно перейдёт на новый компонент при смене сезона.

LauncherIconSwitch используется реальным Android backend: сначала enable выбранного alias с DONT_KILL_APP, проверка, затем disable остальных известных alias, проверка эксклюзивности. Главная LaunchActivity не входит в список переключаемых компонентов. Проверенные настройки записываются после операций PackageManager; при отказе записи предпринимается rollback к прежнему компоненту. При отказе ОС не выдаётся успех. При повреждённых типах/значениях launcher-настроек восстанавливается безопасный Tetogram Default; история и конфигурация аккаунтов не затрагиваются.

После Apply логически активен один launcher alias; OEM может некоторое время показывать устаревший кэш. Приложение не очищает данные и не перезапускает лаунчер. Pinned shortcut — отдельная явно созданная пользователем плитка; он не считается вторым активным системным alias.

## Календарь и системные ограничения

Март–май SPRING, июнь–август SUMMER, сентябрь–ноябрь AUTUMN, декабрь–февраль WINTER, включая 29 февраля. Calendar устройства определяет местный месяц. При ручном режиме дата не влияет на выбранный сезон. Auto не меняет бренд.

Проверка при ApplicationLoader startup, LaunchActivity foreground, DATE_CHANGED/TIME_CHANGED/TIMEZONE_CHANGED и ручном Apply. Receiver действует в процессе приложения; нет polling, alarm, постоянного service или новых permissions. Остановленное приложение не гарантирует смену ровно в полночь: обновление произойдёт при ближайшем разрешённом событии/запуске.

## Безопасная область

Новые wrappers целиком помещают исходный квадрат внутрь гарантированного центрального круга: inset28.5% → 46.44dp сторона → диагональ65.68dp < safe circle66dp. Внутри preview соответствующий scale0.645. Оригинальные файлы не меняются; слой background без stroke заполняет маску, нового непрозрачного обрамления/второго crop нет. Пропорции квадратного рисунка сохраняются. Это консервативный масштаб ради сохранения всего рисунка. В новых иллюстрированных вариантах не задаётся monochrome T: он подменял бы персонажей буквой T в themed icons. Автоматическая тонировка конкретного OEM остаётся настройкой ОС и требует проверки on/off. Отдельные foreground/background originals нужны для варианта full-bleed без полей. Legacy wrappers оставлены прежними ради миграции.
