# Ручная проверка на Android

Статус всех пунктов: **не проверено**. Выполняется владельцем после успешной сборки. Агент не использует реальные аккаунты без отдельного разрешения. Запишите commit, SHA-256 APK, Android/API, модель устройства, сертификат и результат каждого пункта без токенов, телефонов, кодов входа и содержимого личных сообщений в публичных логах.

- [ ] APK устанавливается с package `org.tetogram.messenger`; официальный Telegram остаётся установлен и его данные доступны.
- [ ] В launcher отображаются Tetogram и собственная фиолетовая иконка T, включая Android adaptive/themed icon, launcher aliases, splash, вводный экран и заголовок чатов.
- [ ] Приложение запускается без crash, показывает настоящий экран авторизации и русский язык при первой установке.
- [ ] Можно войти в существующий Telegram-аккаунт разрешённым сервером способом и подтвердить 2FA при её наличии.
- [ ] Загружается настоящий список чатов, папки и архив.
- [ ] Открываются личная переписка, группа и канал; история и поиск работают.
- [ ] Текст отправляется и принимается с подтверждением сервера. Проверяются edit/delete/forward/reply/reactions/pins/scheduled/drafts.
- [ ] Изображение и документ отправляются/скачиваются/открываются; проверяются видео, голос, видеосообщения, музыка, GIF, stickers и emoji.
- [ ] Уведомления приходят в foreground/background, после блокировки и перезапуска; отдельно проверить FCM и ограничения батареи/Android 13+ permission.
- [ ] Несколько аккаунтов добавляются и переключаются без смешивания чатов, уведомлений, кеша и контактов.
- [ ] Выход из аккаунта Tetogram не удаляет Android-аккаунты официального Telegram; синхронизация контактов не смешивает custom MIME-записи.
- [ ] Работают голосовые и видеозвонки, микрофон, камера, Bluetooth/динамик и foreground service.
- [ ] Работают секретные чаты и обмен медиа в них; шифрование не отключено.
- [ ] Проверены профили, settings/privacy, темы, жесты, анимации, поворот, крупный шрифт и accessibility.
- [ ] Проверены истории, боты, Mini Apps и существующие возможности Premium аккаунта; отдельно записаны ограничения покупок и провайдеров.
- [ ] Ссылки t.me/tg:// предлагают корректный выбор клиента, вложения FileProvider и Android widgets открываются в Tetogram.
- [ ] Обновление APK с той же подписью сохраняет данные Tetogram; официальный Telegram продолжает работать.

Для каждого сбоя добавляйте шаги воспроизведения, ожидаемое/фактическое поведение и обезличенный stack trace в TROUBLESHOOTING. Не отмечайте функцию рабочей по наличию класса в исходниках или успешной компиляции.

## 0.2.0: удалённые сообщения — проверка на устройстве

Все пункты ниже пока НЕ выполнены агентом. Проверять только с согласия владельцев тестовых аккаунтов. Сохранение включается вручную в Settings → Tetogram Labs после предупреждения. Не используйте секретные/исчезающие сообщения для обычных тестов архива.

- [ ] Получить обычное входящее сообщение, удалить со второго аккаунта: в исходном месте остаётся локальная копия с красной корзиной и исходной датой.
- [ ] Удалить несколько сообщений, включая медиаальбом: порядок, группировка, подпись и прокрутка сохраняются.
- [ ] Повторить удаление в обычной группе.
- [ ] Повторить в канале/супергруппе, включая одинаковые message ID в разных каналах.
- [ ] После получения сообщения закрыть Tetogram, удалить сообщение со второго аккаунта, запустить Tetogram: обработанное серверное событие отмечает сохранённый снимок.
- [ ] Перезапустить после удаления: локальная копия остаётся доступна в чате и списке.
- [ ] Удалить сообщение, не полученное/не сохранённое клиентом: выдуманной копии нет.
- [ ] Выключить функцию/показ: новые снимки не создаются, локальные копии исчезают из чата после сверки; существующий архив удаляется только отдельной очисткой.
- [ ] Очистить архив при открытом чате: локальные копии исчезают, серверные сообщения остаются.
- [ ] Проверить два аккаунта: настройки, поиск и очистка не затрагивают другой аккаунт.
- [ ] Удалить во время просмотра переписки: нет сбоя, скачков дат, нарушений прокрутки и недопустимых серверных действий над копией.
- [ ] Повторно получить событие удаления: одна копия, первая дата обнаружения не меняется.

Дополнительно: RU/EN, светлая/тёмная тема, маленький экран, переход к сообщению/ответу, пагинация большой истории, исключённые чаты, сроки хранения, поиск, удаление одной копии. Secret chat, TTL, одноразовые медиа и защищённый контент не должны попадать в архив. Проверить авторизацию, отправку, уведомления, звонки, Premium и Mini Apps по основному списку регрессий.

SQL/JUnit проверки в CI подтверждают правила и операции хранения, но не заменяют эти Android-сценарии. Старую установленную 0.1.0 нельзя обновить новым сертификатом; приложение/его данные автоматически не удалять. Проверять новую подпись на отдельном устройстве либо после осознанно выбранной владельцем чистой установки.
