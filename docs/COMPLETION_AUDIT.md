# Проверка оставшихся недоработок — code209

Исторические CHANGELOG/APK receipts сохраняют прежние ограничения своих сборок; это не список ограничений актуального кода.

| Область | Текущее состояние | Ограничения/приёмка |
|---|---|---|
| История правок | Вместо «недоступно»: SQLite ledger до overwrite, отдельное согласие/default off, old/new, mark, Labs/меню, очистка/retention/UID | Неизвестный текст не восстанавливается. Android MTProto/JNI/UI — EDIT_HISTORY.md, NOT RUN |
| Баннеры других профилей | ProfileActivity открывает существующий редактор для profile:user/profile:-chat. UID владельца медиа отделён от target. До explicit override чужие профили остаются native | Публичные фотографии не меняются. Скролл/видео/ориентация на устройстве NOT RUN |
| Переход профиля | Штатный AnimatorSet учитывает существующие effects.durationScale/enabled/system/battery gates; второго параметра нет | Новые произвольные типы перехода не создаются; сохраняются native кривые/геометрия. Визуальная проверка NOT RUN |
| Сезонные иконки | Все 8 изображений встроены со сборки189 | One UI/кэш лаунчера/дата проверяются на телефоне |
| Жестовые обои | Реализованы в code199, сохранены | GPU/decoder/жесты/EXIF/визуальное совпадение — ручной WALLPAPER_POSITIONING.md |
| Пользовательская иконка | Встроенные aliases и отдельный pinned shortcut | Android не заменяет настоящую иконку APK произвольным файлом; shortcut требует явного действия |
| Local Reply | Текст и captions через server blockquote + local Reply | Некоторые media-типы не имеют caption; фиктивная reply metadata не отправляется. DELETED_REPLIES.md |
| Billing/Premium/admin/server wallpaper | Штатные возможности сохранены | Серверные права не обходятся; Billing требует регистрации package и внешних настроек |

Локальные профили: профиль → меню ⋮ → «Локальное оформление профиля». Редактор использует прежние draft/Apply/Cancel, media pipeline, scopes и аккаунты. Полный reset удаляет локальное переопределение. В собственном профиле прежние глобальные баннеры сохраняются; чужие без настройки не меняются. В scope подписи указано имя выбранного профиля.

Успешная компиляция не подменяет ручную приёмку на Samsung. Реклама Telegram, Secrets, подпись и applicationId не изменяются. Новая база сессий или независимая система тем не создаётся.
